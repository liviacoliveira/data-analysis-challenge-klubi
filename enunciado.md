## 📘 Teste Prático — Analytics Engineer (Estágio)

Bem-vindo(a) ao nosso desafio técnico!

### Objetivo

Avaliar sua capacidade de:

1. Explorar e entender dados;
2. Transformar e preparar dados para análise;
3. Identificar padrões que influenciam nas análises;
4. Utilizar os dados de forma a gerar valor;
5. Comunicar conclusões de forma clara, estruturada e orientada a insights.

---

### Base de Dados

O dataset contém informações de alunos e seus hábitos, como:

* horas de estudo por dia
* tempo em redes sociais
* estado de saúde mental
* frequência de exercícios
* qualidade da dieta
* desempenho escolar
* variáveis demográficas

O arquivo será fornecido em `.csv`.

---

### Tarefas

1. **Exploração inicial**

   * Importar e descrever a base (tipos, distribuição, valores ausentes).
   * Diagnóstico de qualidade dos dados.

2. **Engenharia de dados**

   * Criar variáveis derivadas se fizer sentido (ex.: faixas de uso de redes sociais).
   * Explicar como tratou dados ausentes ou inconsistentes.

3. **Análise estatística**

   * Calcular correlações entre hábitos e notas.
   * Identificar quais variáveis possuem maior influência positiva e negativa.

4. **Aplicações práticas para os dados**

   * Até aqui a base foi descrita. Agora queremos ver o que dá para **fazer** com ela.
   * Construa pelo menos uma aplicação concreta. Alguns caminhos possíveis:

     * uma forma de prever o comportamento de um aluno novo a partir dos hábitos dele;
     * um app interativo (ex.: Streamlit) em que seja possível simular cenários;
     * uma segmentação de alunos que oriente algum tipo de ação;
     * qualquer outra ideia sua.
   * Explique a escolha: que decisão essa aplicação apoia e quem a usaria.

5. **Visualização**

   * No mínimo 3 gráficos:

     * mapa de calor de correlação;
     * análise detalhada de uma variável com maior impacto;
     * comparação por faixas (boxplot ou histogramas).
   * Dashboard não é obrigatório, mas é um diferencial.

6. **Síntese de insights**

   * Quais hábitos mais afetam as notas?
   * Que recomendações práticas surgem dos dados?
   * Há diferenças entre grupos (ex.: gênero, saúde mental, etc.)?

---

### Ferramentas

Use o que preferir — linguagem, bibliotecas, frameworks e assistentes de IA.

O que vamos ler é o resultado: as decisões que você tomou, o que construiu em cima da análise e a clareza com que explica o porquê de cada escolha. Descrever a base é o ponto de partida; o que diferencia uma entrega é o que ela permite fazer depois.

---

### O que será avaliado

| Critério                         | Observação                              |
| -------------------------------- | --------------------------------------- |
| Clareza na análise               | Organização, narrativa e lógica         |
| Qualidade da engenharia de dados | Transformações adequadas e justificadas |
| Correção estatística             | Interpretação coerente das relações     |
| Aplicações práticas              | Formas de tornar os dados úteis         |
| Visualizações                    | Relevância + leitura fácil              |
| Comunicação de insights          | Conclusões práticas                     |

Um repositório público no GitHub com o seu projeto e um README explicando como rodá-lo e quais foram as suas conclusões.
